# AI Lunch Recommendation

내 주변 500m 이내의 식당을 찾아 오늘의 점심을 추천해 주는 간단한 웹 애플리케이션입니다.

## 프로젝트 소개

이 프로젝트는 사용자의 현재 위치를 기반으로 주변 식당을 검색하고, 그 중 하나를 무작위로 추천해주는 단일 페이지 웹 앱입니다.

## 주요 기능

- 현재 위치 기반 주변 식당 검색
- 500m 반경 내 음식점 탐색
- 추천 결과 카드 표시
- 카카오맵 상세 정보 링크 제공
- 브라우저에서 바로 실행 가능한 간단한 구조

## 사용 방법

1. 웹 브라우저에서 [ogq3.html](ogq3.html) 파일을 열거나, Live Server로 실행합니다.
2. 화면의 버튼을 클릭합니다.
3. 브라우저의 위치 권한을 허용하면 주변 식당을 검색합니다.
4. 추천된 식당의 상세 정보를 확인할 수 있습니다.

## 실행 환경

- HTML
- JavaScript
- Kakao Maps JavaScript SDK

## 참고 사항

- 위치 정보 사용을 위해 브라우저의 위치 권한이 필요합니다.
- 카카오 지도 API를 사용하므로, 필요 시 해당 앱 키를 갱신하거나 교체해야 할 수 있습니다.
- 위치 권한이 거부되면 기본 좌표 기준으로 동작합니다.
